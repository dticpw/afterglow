# 余晖航线 · AFTERGLOW

一个可直接在浏览器中游玩的太空生存射击原型。使用原生 HTML、CSS、JavaScript 和 Canvas 2D，星空、行星、飞船和粒子效果均由程序绘制，无需安装依赖。

**[在线试玩](https://koa-ol.com/games/afterglow/)** · [Koa-OL Games](https://koa-ol.com/games/)

## 操作

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动飞船 |
| 空格 | 冲刺，3 秒冷却，短暂无敌 |
| P / Esc | 暂停或继续（Esc 在全屏时用于退出全屏） |
| 触屏摇杆与冲刺按钮 | 移动端操作 |

当前版本自动瞄准并双发射击。每 20 秒升级一波敌人并恢复部分护盾，60 秒后旗舰抵达；摧毁旗舰获胜。每击破 12 个敌人掉落修复胶囊，靠近可收取。

- 支持自动驾驶演示，使用相同战斗规则，可能失败。
- 默认静音，右上角可开启合成音效。
- 支持返回主页、浏览器全屏；不支持全屏的浏览器会显示提示。
- 本机最高分只记录手动试玩；自动演示不计入。
- 最高分保存在当前浏览器的当前网站来源中，清理站点数据会清除记录；存储不可用时仅在本次会话保留。
- 切换标签页自动暂停。

## 运行

下载或克隆本仓库，双击 `index.html` 即可游玩。游戏运行不依赖外部素材或后端，返回主页链接需要联网。

也可以用任意静态网站服务器提供本目录；无需打包或构建。不同端口、域名和直接打开文件的存储空间可能不同，不共享最高分。

## 文件

- `index.html`：游戏界面。
- `style.css`：响应式布局和界面样式。
- `game.js`：输入、战斗、渲染、音效、全屏和最高分。
- `favicon.svg`：图标。

线上版本由个人主页站点发布，本仓库保存独立游戏源码；向本仓库提交不自动更新个人主页。

## 当前状态与验证

这是可试玩原型，尚无账号、云存档、全球排行榜或多人模式。

已检查桌面 1440×900 和移动尺寸 390×844 的布局，实测移动、冲刺、暂停、全屏和返回主页；验证最高分刷新保留、演示不计分、存储失败降级。移动尺寸检查不等于手机真机性能验证。三次加速战斗逻辑模拟曾成功通关，不代表每局必胜。

后续拟探索鼠标驾驶：鼠标决定方向，距离决定速度，子弹沿机头发射，并降低前期敌人压力。**该方案尚未实现，本次保留当前已上线版本。**
