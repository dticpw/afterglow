# Afterglow v0.2

一个可直接在浏览器中游玩的太空生存射击原型。使用原生 HTML、CSS、JavaScript 和 Canvas 2D，星空、行星、飞船、流光拖尾和粒子效果均由程序绘制，无需安装依赖。

**[在线试玩](https://koa-ol.com/games/afterglow/)** · [Koa-OL Games](https://koa-ol.com/games/)

## 操作

| 操作 | 功能 |
| --- | --- |
| 鼠标（默认） | 指向航向，拉远加速，靠近刹车 |
| WASD / 方向键（需选择键盘驾驶） | 控制航向，松开刹车 |
| 空格 | 冲刺，3 秒冷却，短暂无敌 |
| P / Esc | 暂停或继续（Esc 在全屏时用于退出全屏） |
| 触屏摇杆与冲刺按钮 | 移动端操作 |

当前版本沿机头自动双发射击，手动模式不自动索敌。首页可选择鼠标、键盘或触屏驾驶；触屏设备默认摇杆。鼠标附近有 24 px 停车区，距离约 220 px 时达到最大推力，急转弯会降速。每 20 秒升级一波敌人并恢复部分护盾，60 秒后旗舰抵达；摧毁旗舰获胜。每击破 12 个敌人掉落修复胶囊，靠近可收取。

- 支持自动驾驶演示，使用相同战斗规则，可能失败。
- 默认静音，右上角可开启合成音效。
- 支持返回主页、浏览器全屏；不支持全屏的浏览器会显示提示。
- 本机最高分只记录手动试玩；自动演示不计入。
- v0.2 最高分按驾驶方式分别保存在当前浏览器的当前网站来源中，保留但不混入 v0.1 的旧纪录；清理站点数据会清除记录；存储不可用时仅在本次会话保留。
- 切换标签页、鼠标离开窗口或窗口失焦时自动暂停。恢复后先停住，移动鼠标或重新操作才能继续驾驶。

## 运行

下载或克隆本仓库，双击 `index.html` 即可游玩。游戏运行不依赖外部素材或后端，返回主页链接需要联网。

也可以用任意静态网站服务器提供本目录；无需打包或构建。不同端口、域名和直接打开文件的存储空间可能不同，不共享最高分。

## 文件

- `index.html`：游戏界面。
- `style.css`：响应式布局和界面样式。
- `game.js`：输入、战斗、渲染、音效、全屏和最高分。
- `flight.js`：各驾驶方式共用的转向、速度与冲刺逻辑。
- `tests/flight.test.cjs`：基于 Node 内置测试器的飞行回归测试。
- `CHANGELOG.md`：v0.1、v0.2 版本变化。
- `favicon.svg`：图标。

线上版本由个人主页站点发布，本仓库保存独立游戏源码；向本仓库提交不自动更新个人主页。

## 当前状态与验证

这是可试玩原型，尚无账号、云存档、全球排行榜或多人模式。

已检查桌面 1440×900 和移动尺寸 390×844 的布局，实测鼠标转向变速、键盘与摇杆输入、暂停恢复、失焦暂停、沿机头射击和普通敌人单发。飞行测试覆盖距离速度、停车、掉头、原地瞄准、静止冲刺与帧率一致性。移动尺寸检查不等于手机真机性能验证。

v0.2 三次加速自动驾驶模拟中，一次约 145 秒通关，另两次约 99、115 秒阵亡。自动演示不保证必胜，这些模拟不能替代玩家手感评估。

开发验证（需要 Node.js；游戏运行不需要）：

```sh
node --test tests/flight.test.cjs
```

这条命令运行飞行回归测试，不安装依赖、不改存档。

飞船新增随速度变化的青绿／淡紫流光拖尾，冲刺时加强，停车后自然消散；减少动态效果偏好下缩短拖尾并关闭光晕。游戏名称恢复为 Afterglow，原仓库、试玩 URL 和存档键保留兼容。
